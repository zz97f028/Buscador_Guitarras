# Interfaz web de Acorde

Sigue las instrucciones de [arranque local](../README.md#arranque-local) desde
la raíz del proyecto. Con el servidor Python en el puerto 8000 y esta interfaz
en marcha, abre <http://localhost:5173>.

Vite reenvía las rutas `/api` al servidor local; la clave de OpenAI permanece
únicamente en el servidor.
